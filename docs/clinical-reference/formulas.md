# Clinical Formulas

| Measure | Formula |
|---------|---------|
| BMI | weight (kg) / height (m)² |
| BSA (Mosteller) | √(height cm × weight kg / 3600) m² |
| Ideal body weight (Devine) | Men 50 kg + 2.3 kg per inch over 5 ft; women 45.5 kg + 2.3 kg per inch over 5 ft |
| Creatinine clearance (Cockcroft-Gault) | [(140 − age) × weight kg] / (72 × SCr mg/dL); × 0.85 if female |
| eGFR (CKD-EPI 2021) | 142 × min(SCr/κ, 1)^α × max(SCr/κ, 1)^−1.200 × 0.9938^age × 1.012 [if female]; κ = 0.7 (F) / 0.9 (M); α = −0.241 (F) / −0.302 (M) |
| Corrected calcium | measured Ca (mg/dL) + 0.8 × (4.0 − albumin g/dL) |
| Anion gap | Na⁺ − (Cl⁻ + HCO₃⁻); normal ≈ 8–12 mmol/L (lab-dependent) |
| Corrected sodium (hyperglycemia) | Na⁺ + 1.6 × [(glucose mg/dL − 100) / 100] (Katz; some use 2.4) |
| Serum osmolality (calculated) | 2 × Na⁺ + glucose/18 + BUN/2.8 (mg/dL units) |
| Mean arterial pressure | (SBP + 2 × DBP) / 3 |
| QTc (Bazett) | QT / √RR (seconds) |
| Parkland (burns) | 4 mL × kg × %TBSA over 24 h; half in first 8 h from time of burn |
| Maintenance fluids (4-2-1, children) | 4 mL/kg/h first 10 kg + 2 mL/kg/h next 10 kg + 1 mL/kg/h each kg above 20 |

## Unit conversions
| Analyte | mg/dL → mmol/L (or µmol/L) |
|---------|---------------------------|
| Glucose | ÷ 18 |
| Creatinine | × 88.4 (µmol/L) |
| Urea nitrogen → urea | × 0.357 |
| Cholesterol | ÷ 38.67 |
| Triglycerides | ÷ 88.57 |
| Calcium | ÷ 4 (approx. 0.25) |
| HbA1c % → mmol/mol | (% − 2.15) × 10.929 |
| Temperature | °F = °C × 9/5 + 32 |
| Weight | 1 kg = 2.2046 lb |
