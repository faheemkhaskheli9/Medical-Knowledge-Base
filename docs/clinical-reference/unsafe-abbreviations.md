# Unsafe Abbreviations — never use

| Do not use | Problem | Write instead |
|------------|---------|---------------|
| U, u | Mistaken for 0, 4, cc | "units" |
| IU | Mistaken for IV or 10 | "international units" |
| Q.D., QD, Q.O.D., QOD | Confused with each other | "daily", "every other day" |
| Trailing zero (5.0 mg) | Read as 50 mg | 5 mg |
| No leading zero (.5 mg) | Read as 5 mg | 0.5 mg |
| MS, MSO₄, MgSO₄ | Morphine vs magnesium sulfate | Full drug name |
| µg | Mistaken for mg | "mcg" |
| cc | Mistaken for U | "mL" |
| SC, SQ, sub q | Mistaken for SL or "every" | "subcut" |
| HS | Half-strength vs bedtime | "half-strength" or "at bedtime" |
| D/C | Discharge vs discontinue | Full word |
