# Adult Lab Reference Ranges

> Ranges are approximate and **lab-specific**. Always use the range printed on the patient's report. Not valid for children or pregnancy.

## Electrolytes & renal
| Test | Conventional | SI |
|------|-------------|----|
| Sodium | 135–145 mEq/L | 135–145 mmol/L |
| Potassium | 3.5–5.0 mEq/L | 3.5–5.0 mmol/L |
| Chloride | 98–107 mEq/L | 98–107 mmol/L |
| Bicarbonate | 22–29 mEq/L | 22–29 mmol/L |
| Urea nitrogen (BUN) | 7–20 mg/dL | 2.5–7.1 mmol/L (urea) |
| Creatinine | 0.6–1.2 mg/dL | ~53–106 µmol/L |
| Calcium (total) | 8.5–10.5 mg/dL | 2.12–2.62 mmol/L |
| Magnesium | 1.7–2.2 mg/dL | 0.70–0.91 mmol/L |
| Phosphate | 2.5–4.5 mg/dL | 0.81–1.45 mmol/L |

## Glucose & diabetes (ADA)
| Test | Normal | Prediabetes | Diabetes |
|------|--------|-------------|----------|
| Fasting glucose | < 100 mg/dL (5.6 mmol/L) | 100–125 mg/dL | ≥ 126 mg/dL (7.0 mmol/L) |
| HbA1c | < 5.7% (39 mmol/mol) | 5.7–6.4% | ≥ 6.5% (48 mmol/mol) |
| 2-h OGTT | < 140 mg/dL (7.8 mmol/L) | 140–199 mg/dL | ≥ 200 mg/dL (11.1 mmol/L) |

## Hematology
| Test | Range |
|------|-------|
| Hemoglobin | Men 13.5–17.5 g/dL; women 12.0–15.5 g/dL |
| WBC | 4.0–11.0 × 10⁹/L |
| Platelets | 150–400 × 10⁹/L |
| MCV | 80–100 fL |
| INR (no anticoagulant) | ~0.8–1.2 |

## Liver
| Test | Range |
|------|-------|
| ALT | ~7–56 U/L (lab-dependent) |
| AST | ~10–40 U/L |
| ALP | ~44–147 U/L |
| Total bilirubin | 0.1–1.2 mg/dL (2–21 µmol/L) |
| Albumin | 3.5–5.0 g/dL (35–50 g/L) |

## Other
| Test | Range |
|------|-------|
| TSH | ~0.4–4.0 mIU/L |
| Lactate | 0.5–2.0 mmol/L |
| Arterial pH | 7.35–7.45 |
| PaCO₂ | 35–45 mmHg (4.7–6.0 kPa) |
| PaO₂ (room air) | 75–100 mmHg (10–13.3 kPa) |
