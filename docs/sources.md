# Trusted Sources

## Evidence hierarchy (highest first)
1. Current official clinical practice guidelines (WHO, NICE, CDC, ADA, AHA/ACC, ESC, IDSA, GINA, GOLD, KDIGO)
2. Systematic reviews and meta-analyses (Cochrane)
3. Randomized controlled trials
4. Cohort / case-control studies
5. Case reports, expert opinion

## Drug information
| Source | Use | Access |
|--------|-----|--------|
| FDA labels (DailyMed) | US official prescribing information | Free — dailymed.nlm.nih.gov |
| openFDA | Adverse events, labels, recalls | Free API — open.fda.gov |
| EMA SmPC | EU product information | Free — ema.europa.eu |
| BNF / BNFc | UK dosing (adult / children) | bnf.nice.org.uk (UK free) |
| WHO Model List of Essential Medicines | Core medicines | Free — who.int |
| WHO ATC/DDD index | Drug classification | Free — atcddd.fhi.no |
| RxNorm (NLM) | Normalized drug names and codes | Free API |
| LactMed (NLM) | Drugs in breastfeeding | Free — ncbi.nlm.nih.gov/books/NBK501922 |
| Lexicomp, Micromedex, UpToDate, DrugBank | Comprehensive references | Licensed |

## Citation format
`<Source>, <Title/section>, <Year or version>` — e.g. `KDIGO 2024 CKD Guideline, Rec 1.1.1`.
