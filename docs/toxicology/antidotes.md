# Poisoning and Antidotes

!!! danger "Any suspected poisoning"
    Contact emergency services or the local poison center immediately. Supportive care (airway, breathing, circulation) comes first. Doses are not listed here — use a toxicology service.

| Poison / drug | Antidote / specific treatment | Notes |
|---------------|-------------------------------|-------|
| Paracetamol (acetaminophen) | Acetylcysteine | Start based on nomogram level or ingestion history; most effective within 8 h |
| Opioids | Naloxone | Short half-life — repeat doses or infusion may be needed |
| Benzodiazepines | Flumazenil | Not routine: may precipitate seizures in dependence or with pro-convulsant co-ingestion |
| Warfarin / vitamin K antagonists | Vitamin K; 4-factor PCC for major bleeding | |
| Dabigatran | Idarucizumab | |
| Apixaban, rivaroxaban | Andexanet alfa or 4-factor PCC | Availability varies |
| Heparin | Protamine sulfate | Partial reversal of LMWH |
| Digoxin | Digoxin-specific antibody fragments (Fab) | |
| Organophosphates / carbamates | Atropine + pralidoxime | Decontaminate; protect staff |
| Methanol, ethylene glycol | Fomepizole (or ethanol); hemodialysis | |
| Cyanide | Hydroxocobalamin | |
| Carbon monoxide | 100% oxygen; consider hyperbaric oxygen | SpO₂ falsely normal — use co-oximetry |
| Iron | Deferoxamine | |
| Tricyclic antidepressants | Sodium bicarbonate (QRS widening, arrhythmia) | |
| Beta-blockers | Glucagon; high-dose insulin euglycemia therapy | |
| Calcium channel blockers | Calcium; high-dose insulin euglycemia therapy | |
| Sulfonylureas | Glucose + octreotide | Prolonged hypoglycemia — observe |
| Methemoglobinemia (e.g. dapsone, nitrites, local anesthetics) | Methylene blue | Avoid in G6PD deficiency |
| Isoniazid | Pyridoxine (vitamin B6) | Seizures |
| Local anesthetic systemic toxicity | 20% lipid emulsion | |
| Methotrexate | Folinic acid (leucovorin); glucarpidase | |
| Anticholinergic toxicity | Physostigmine (selected cases, specialist) | |
| Malignant hyperthermia | Dantrolene | |
| Serotonin syndrome | Stop serotonergic drugs; supportive; cyproheptadine | |
| Snake envenomation | Species-specific antivenom | Regional poison center |
