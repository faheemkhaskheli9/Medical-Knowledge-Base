# Pregnancy and Lactation

- FDA letter categories (A/B/C/D/X) were replaced by narrative labeling (PLLR) from 2015. Do not cite letters as current.
- Use LactMed for breastfeeding questions.

## Known teratogens / avoid in pregnancy (examples)
| Drug | Concern |
|------|---------|
| Isotretinoin, acitretin | Severe birth defects; pregnancy prevention programs required |
| Valproate | Neural tube defects, neurodevelopmental disorders |
| Warfarin | Embryopathy |
| ACE inhibitors, ARBs | Fetal renal toxicity (2nd/3rd trimester); generally avoid throughout |
| Methotrexate | Abortifacient, teratogen |
| Mycophenolate | Miscarriage, malformations |
| Thalidomide, lenalidomide | Limb and other defects |
| Misoprostol | Miscarriage |
| Tetracyclines (from ~2nd trimester) | Tooth discoloration, bone effects |
| NSAIDs (≥ 20 weeks) | Oligohydramnios; ductus arteriosus closure in 3rd trimester |

## Generally preferred options (verify per case)
- Pain/fever: paracetamol.
- Hypertension: labetalol, nifedipine, methyldopa.
- Anticoagulation: low-molecular-weight heparin.
