# Emergency Red Flags

If any of these are present, advise **calling local emergency services immediately** before giving other information.

| Situation | Red flags |
|-----------|-----------|
| Possible heart attack | Chest pain/pressure > a few minutes, radiating to arm/jaw/back, with sweating, breathlessness, nausea |
| Possible stroke (BE-FAST) | **B**alance loss, **E**yes (vision loss), **F**ace droop, **A**rm/leg weakness, **S**peech difficulty, **T**ime to call |
| Anaphylaxis | Throat/tongue swelling, wheeze, breathing difficulty, hypotension, collapse after allergen exposure — epinephrine IM first-line |
| Sepsis | Fever or hypothermia with confusion, fast breathing, low blood pressure, mottled skin, very low urine output |
| Meningitis | Fever + severe headache + neck stiffness, non-blanching rash, photophobia, altered consciousness |
| Breathing | Severe shortness of breath, cyanosis, inability to speak in sentences, SpO₂ < 92% |
| Bleeding | Vomiting blood, black/tarry stools, uncontrolled bleeding, bleeding on anticoagulants after head injury |
| Head injury | Loss of consciousness, repeated vomiting, seizure, worsening headache, confusion |
| Abdomen | Sudden severe pain, rigid abdomen, pain + pregnancy possible (ectopic) |
| Back pain (cauda equina) | Saddle numbness, new urinary retention/incontinence, bilateral leg weakness |
| Diabetes | Glucose < 3.0 mmol/L (54 mg/dL) with confusion; vomiting, abdominal pain, deep breathing, ketones (DKA) |
| Pregnancy | Heavy bleeding, severe headache with visual changes, reduced fetal movement, seizures |
| Infants | Fever ≥ 38 °C in infant < 3 months, poor feeding, lethargy, bulging fontanelle |
| Mental health | Suicidal intent or plan, self-harm, psychosis with risk to self/others |
| Poisoning/overdose | Any suspected overdose — contact poison center even if asymptomatic (e.g. paracetamol toxicity is delayed) |
