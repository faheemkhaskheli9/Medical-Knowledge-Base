# High-Alert Medications

Medicines with heightened risk of significant harm when used in error. Double-check dose, units, route, and patient factors.

| Medicine / class | Key risk |
|------------------|----------|
| Insulin (all forms, esp. U-500 and IV) | Hypoglycemia; "U" misread as 0; units vs mL confusion |
| Opioids (esp. fentanyl, methadone, hydromorphone) | Respiratory depression; morphine/hydromorphone confusion |
| Anticoagulants (warfarin, heparin, LMWH, DOACs) | Bleeding; heparin concentration errors |
| Oral methotrexate (non-oncology) | Fatal toxicity when taken daily instead of weekly |
| Concentrated potassium chloride / phosphate injection | Fatal arrhythmia if given undiluted or IV push |
| Hypertonic sodium chloride (> 0.9%) | Osmotic demyelination, fluid overload |
| Magnesium sulfate injection | Toxicity, respiratory depression (esp. obstetrics) |
| Neuromuscular blockers | Paralysis without ventilation |
| Chemotherapy (parenteral and oral) | Narrow therapeutic index |
| Sedation agents (propofol, midazolam IV) | Respiratory depression |
| Sulfonylureas | Prolonged hypoglycemia, esp. older adults/renal impairment |
| Epinephrine IV | Concentration confusion (1 mg/mL vs 0.1 mg/mL) |
| Digoxin | Narrow therapeutic index; toxicity with low K⁺ / renal impairment |
