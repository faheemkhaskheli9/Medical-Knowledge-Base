# Drug Names by Region

Use the **generic (INN) name** in answers. Mention brand names only as examples, labeled by country — brands differ between countries and the same brand can contain different ingredients.

## INN vs US names
| INN (WHO, UK, EU, Pakistan) | US name (USAN) |
|-----------------------------|----------------|
| Paracetamol | Acetaminophen |
| Salbutamol | Albuterol |
| Adrenaline | Epinephrine |
| Noradrenaline | Norepinephrine |
| Glibenclamide | Glyburide |
| Pethidine | Meperidine |
| Lidocaine (formerly lignocaine) | Lidocaine |
| Furosemide (formerly frusemide) | Furosemide |
| Rifampicin | Rifampin |
| Ciclosporin | Cyclosporine |
| Colecalciferol | Cholecalciferol |
| Levothyroxine (thyroxine) | Levothyroxine |
| Hyoscine butylbromide | Scopolamine butylbromide (not US-marketed) |

## Combination names
UK "co-" names: co-amoxiclav (amoxicillin + clavulanic acid), co-trimoxazole (trimethoprim + sulfamethoxazole), co-codamol (codeine + paracetamol), co-careldopa (carbidopa + levodopa).
