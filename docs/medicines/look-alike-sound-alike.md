# Look-Alike / Sound-Alike (LASA) Drug Names

Confirm the indication when a name is ambiguous, and use generic names with Tall Man lettering where helpful.

| Name | Confused with | Risk |
|------|---------------|------|
| hydr**OXY**zine | hydr**ALA**zine | Antihistamine vs antihypertensive |
| cloNIDine | clonazePAM | Antihypertensive vs benzodiazepine |
| Celebrex (celecoxib) | Celexa (citalopram), Cerebyx (fosphenytoin) | Different classes |
| traMADol | traZODone | Opioid vs antidepressant |
| HumaLOG (lispro) | HumuLIN (human insulin) | Rapid-acting vs regular/NPH |
| NovoLOG (aspart) | NovoLIN | Rapid-acting vs regular/NPH |
| HYDROmorphone | morphine | ~5× potency difference — fatal overdoses |
| OxyCONTIN (extended release) | oxyCODONE (immediate release) | Release form |
| vinBLAStine | vinCRIStine | Fatal if dose confused |
| glipiZIDE | glyBURIDE | Different potency/duration |
| predniSONE | prednisoLONE | Different formulations/doses |
| chlorproMAZINE | chlorproPAMIDE | Antipsychotic vs sulfonylurea |
| lamoTRIgine (Lamictal) | terbinafine (Lamisil) | Antiepileptic vs antifungal |
| metFORMIN | metroNIDAZOLE | Antidiabetic vs antibiotic |
| Depo-Provera | Depo-Medrol | Contraceptive vs corticosteroid |
| Losec (omeprazole) | Lasix (furosemide) | PPI vs diuretic |
| methotrexate **weekly** | methotrexate daily | Fatal toxicity — frequency confusion |
