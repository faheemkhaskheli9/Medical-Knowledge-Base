# Herb, Supplement, and Food–Drug Interactions

Always ask about herbal, traditional (e.g. desi/Unani, Ayurvedic), and over-the-counter supplements — patients often do not mention them.

| Product | Interacts with | Effect |
|---------|----------------|--------|
| St John's wort | Oral contraceptives, ciclosporin, tacrolimus, warfarin, DOACs, HIV drugs, digoxin | CYP3A4/P-gp induction → treatment failure |
| St John's wort | SSRIs, SNRIs, triptans, tramadol | Serotonin syndrome |
| Grapefruit juice | Simvastatin, lovastatin, felodipine, some immunosuppressants | CYP3A4 inhibition → toxicity |
| Ginkgo, garlic supplements, high-dose fish oil, turmeric/curcumin | Warfarin, DOACs, antiplatelets, NSAIDs | Increased bleeding risk |
| Ginseng | Warfarin | Reduced INR reported |
| Liquorice (glycyrrhizin) | Diuretics, digoxin, antihypertensives | Hypokalemia, hypertension, digoxin toxicity |
| Kava | Hepatotoxic drugs, alcohol, sedatives | Liver injury; sedation |
| Red yeast rice | Statins, CYP3A4 inhibitors | Contains monacolin K (= lovastatin) |
| Valerian, melatonin, kava | Benzodiazepines, opioids, alcohol | Additive sedation |
| Goldenseal | Many CYP-metabolized drugs (e.g. metformin, midazolam) | Altered drug levels |
| Calcium, iron, magnesium, zinc, antacids | Fluoroquinolones, tetracyclines, levothyroxine, bisphosphonates | Reduced absorption — separate doses |
| Vitamin K–rich foods or supplements (large changes) | Warfarin | Reduced INR — keep intake consistent |
| Potassium supplements, salt substitutes (KCl) | ACE inhibitors, ARBs, spironolactone | Hyperkalemia |
| Tyramine-rich foods (aged cheese, cured meats) | MAO inhibitors, linezolid | Hypertensive crisis |
| Alcohol | Metronidazole (disulfiram-like reaction reported), sedatives, opioids, paracetamol (chronic), metformin | Various |
