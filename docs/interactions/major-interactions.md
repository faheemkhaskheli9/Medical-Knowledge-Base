# Major Drug–Drug Interactions

Not exhaustive. Always check a live interaction checker for the full medication list.

| Combination | Risk | Management |
|-------------|------|------------|
| Nitrates + PDE5 inhibitors (sildenafil, tadalafil) | Severe hypotension | Contraindicated |
| MAOIs + SSRIs/SNRIs/tramadol/linezolid/pethidine | Serotonin syndrome | Contraindicated; washout required |
| SSRIs + tramadol/triptans/fentanyl/linezolid | Serotonin syndrome | Avoid or monitor closely |
| Opioids + benzodiazepines/other CNS depressants | Respiratory depression, death | Avoid; lowest doses if unavoidable |
| Simvastatin/lovastatin + strong CYP3A4 inhibitors (clarithromycin, itraconazole, ketoconazole, HIV protease inhibitors) | Rhabdomyolysis | Contraindicated |
| Simvastatin + amiodarone or amlodipine | Myopathy | Simvastatin max 20 mg/day |
| Simvastatin + diltiazem or verapamil | Myopathy | Simvastatin max 10 mg/day |
| Colchicine + strong CYP3A4/P-gp inhibitors (clarithromycin, cyclosporine) | Fatal colchicine toxicity | Avoid, esp. with renal/hepatic impairment |
| Methotrexate + trimethoprim/co-trimoxazole | Bone marrow suppression | Avoid |
| Allopurinol + azathioprine/mercaptopurine | Myelotoxicity | Avoid or reduce thiopurine dose to ~25% with close monitoring |
| ACE inhibitor/ARB + potassium-sparing diuretic/potassium supplements | Hyperkalemia | Monitor K⁺ and renal function |
| ACE inhibitor/ARB + diuretic + NSAID | Acute kidney injury | Avoid triple combination |
| Lithium + NSAIDs/ACE inhibitors/ARBs/thiazides | Lithium toxicity | Monitor levels; avoid if possible |
| Warfarin + amiodarone/fluconazole/metronidazole/co-trimoxazole | Bleeding (↑ INR) | Reduce dose, monitor INR |
| Clopidogrel + omeprazole/esomeprazole | Reduced antiplatelet effect (CYP2C19) | Prefer pantoprazole if PPI needed |
| Tizanidine + ciprofloxacin/fluvoxamine | Severe hypotension, sedation | Contraindicated |
| Theophylline + ciprofloxacin | Theophylline toxicity | Avoid or monitor levels |
| Fluoroquinolones/tetracyclines + antacids, iron, calcium, zinc | Reduced antibiotic absorption | Separate doses (check label for interval) |
| Multiple QT-prolonging drugs (e.g. macrolides, fluoroquinolones, ondansetron, haloperidol, methadone, citalopram) | Torsades de pointes | Check ECG/electrolytes; avoid combinations |
| Rifampicin + many drugs (oral contraceptives, DOACs, HIV drugs, warfarin) | Treatment failure (CYP induction) | Check each pair |
| Grapefruit juice + simvastatin, some calcium channel blockers | ↑ drug levels | Avoid |
| St John's wort + SSRIs, oral contraceptives, ciclosporin, warfarin | Serotonin syndrome / treatment failure | Avoid |
