# Pharmacogenomics — Key Gene–Drug Pairs

| Gene / allele | Drug(s) | Effect | Action (CPIC/FDA) |
|---------------|---------|--------|-------------------|
| HLA-B\*57:01 | Abacavir | Hypersensitivity reaction | Test before starting; contraindicated if positive |
| HLA-B\*15:02 | Carbamazepine, oxcarbazepine, phenytoin/fosphenytoin | SJS/TEN (higher prevalence in Southeast/South Asian ancestry) | Test before starting in at-risk populations; avoid if positive |
| HLA-A\*31:01 | Carbamazepine | SJS/TEN, DRESS | Consider alternative if positive |
| HLA-B\*58:01 | Allopurinol | SJS/TEN | Avoid if positive; test in high-prevalence populations |
| CYP2C19 poor/intermediate metabolizer | Clopidogrel | Reduced activation → stent thrombosis | Use prasugrel or ticagrelor if no contraindication (ACS/PCI) |
| CYP2D6 ultrarapid metabolizer | Codeine, tramadol | Excess morphine/active metabolite → respiratory depression | Avoid |
| CYP2D6 poor metabolizer | Codeine, tramadol | Inadequate analgesia | Use alternative analgesic |
| TPMT, NUDT15 | Azathioprine, mercaptopurine, thioguanine | Severe myelosuppression | Reduce dose or use alternative per genotype |
| DPYD | Fluorouracil, capecitabine | Severe/fatal toxicity | Reduce dose or avoid per genotype |
| UGT1A1\*28 | Irinotecan | Neutropenia | Reduce starting dose for poor metabolizers |
| CYP2C9, VKORC1 | Warfarin | Altered dose requirement | Genotype-guided dosing algorithms |
| SLCO1B1 decreased function | Simvastatin | Myopathy | Lower dose or alternative statin |
| G6PD deficiency | Rasburicase, primaquine, tafenoquine, dapsone, methylene blue | Hemolysis | Test before use; avoid if deficient |
