# Older Adults (≥ 65 years)

Use the **AGS Beers Criteria** and **STOPP/START** to screen prescriptions.

## Potentially inappropriate examples (Beers)
| Drug / class | Concern |
|--------------|---------|
| First-generation antihistamines (diphenhydramine, chlorphenamine, hydroxyzine) | Anticholinergic: confusion, constipation, urinary retention |
| Benzodiazepines, Z-drugs | Falls, fractures, cognitive impairment |
| Sliding-scale insulin alone | Hypoglycemia without benefit |
| Long-acting sulfonylureas (glibenclamide/glyburide, glimepiride) | Prolonged hypoglycemia |
| Chronic NSAIDs | GI bleeding, renal injury, heart failure |
| Skeletal muscle relaxants | Sedation, anticholinergic effects |
| Tricyclic antidepressants (amitriptyline) | Anticholinergic, orthostatic hypotension |

## Principles
Start low, go slow; review renal function; reduce polypharmacy; assess falls risk.
